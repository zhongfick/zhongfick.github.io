*Java中泛型广泛运用于类和方法上，用于类上的时候通过类名<T>去调用
// 泛型类
public class ApiResult<T> {
    private T data;
    // ... getter/setter
}
ApiResult<Product> res = new ApiResult<>();

用于方法上的时候通过传参去调用
// 泛型方法，参数是泛型
public <K> void handleData(K data) { ... }
Java 里之所以这种写法少，是因为大多数时候编译器能从 Product p = ... 左边推断出来

*TS在调接口的时候运用于方法上，比如
requestClient.get<PageResult<DoudianProductApi.ProductRow>>(...)。这里是强制返回类型为pageresult
这在TS很常见
