*JDK动态代理

核心在于 Proxy 和 Invocationhandler 这两个类
继承Invocationhandler类，也就是说明这个类里面要抓对象做动态代理了

 static class LogInvocationHandler implements InvocationHandler

类本身有一个方法invoke，里面就是要写的增强方法

public Object invoke(Object proxy, Method method, Object[] args) throws Throwable

调用的时候创建对象创建handler，通过Proxy类的方法，例如

OrderService proxyService = (OrderService) Proxy.newProxyInstance(
                realService.getClass().getClassLoader(),
                realService.getClass().getInterfaces(), // 关键：只能代理接口
                handler);

Proxy创建代理对象，通过getclass.getclassloader获得类加载器
                  通过getclass.getInterfaces获得类实现的所有接口，java是单继承但可以实现多接口   （所以是“所有”）
                  handler就是创造出来的invocationhandler
